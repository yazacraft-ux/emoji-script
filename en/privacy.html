PRIVACY

Privacy policy

Last updated: 13 September 2026

No personal data collection

The Emoji Script Chrome extension does not collect, sell, share or transmit any personal data to a server or to a third party.

Local notes

Any text typed into the notes area of the extension is stored on the user’s device only, through the local storage of the extension context. It is never sent to emoji-script.com or to any other server.

No tracking

The extension includes no analytics tool, no advertising tracker and no profiling system. It does not track browsing history, clicks on other sites or user activity outside the extension.

Permissions and remote code

The extension requests no sensitive permission and runs no remote JavaScript or WebAssembly code. All the code it needs is included in the extension package.

External links

Some buttons open the official website emoji-script.com, in particular the compiler, the documentation and the examples.

Contact

For any question about the extension or this privacy policy, you can get in touch through the official Emoji Script website.
