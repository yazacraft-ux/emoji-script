Politique de confidentialité

Dernière mise à jour : 13 septembre 2026

Aucune collecte de données personnelles

L’extension Chrome Emoji Script ne collecte, ne vend, ne partage et ne transmet aucune donnée personnelle à un serveur ou à un tiers.

Bloc-notes local

Le texte éventuellement saisi dans le bloc-notes de l’extension est enregistré uniquement sur l’appareil de l’utilisateur, via le stockage local du contexte de l’extension. Il n’est jamais envoyé à emoji-script.com ni à un autre serveur.

Aucun suivi

L’extension n’intègre aucun outil d’analyse, aucun traceur publicitaire et aucun système de profilage. Elle ne suit pas l’historique de navigation, les clics sur d’autres sites ou l’activité de l’utilisateur en dehors de l’extension.

Permissions et code distant

L’extension ne demande aucune permission sensible et n’exécute aucun code JavaScript ou WebAssembly distant. Tout le code nécessaire à son fonctionnement est inclus dans le package de l’extension.

Liens externes

Certains boutons ouvrent le site officiel emoji-script.com, notamment le compilateur, la documentation et les exemples.

Contact

Pour toute question concernant l’extension ou cette politique de confidentialité, tu peux passer par le site officiel Emoji Script.
