Questions fréquentes

Tout ce qu’il faut savoir.

L’extension est-elle gratuite ?

Oui. L’extension Emoji Script est gratuite.

Est-ce que vous collectez des données ?

Non. L’extension ne collecte pas de données personnelles. Le bloc-notes reste stocké localement dans ton navigateur.

À quoi sert l’extension ?

Elle sert de raccourci permanent vers le compilateur, la syntaxe, les exemples et la documentation Emoji Script.

Comment accéder au compilateur ?

Clique sur l’icône Emoji Script dans Chrome puis sur « Ouvrir le compilateur ».
